Theoretical Foundations

Mathematical Formulations & Graph Geometry

Engineered for academic rigour and aligned with university research curricula (e.g. Politecnico di Milano, Politecnico di Torino).

1. Continuous Euclidean Distance

Evaluates continuous 2D metric distances between all localized pedestrian bounding box centroids $(x_i, y_i)$ and $(x_j, y_j)$:

d(i, j) = √((xi - xj)2 + (yi - yj)2)

Calculated across all $\binom{N}{2}$ combinations to construct the social graph adjacency matrix.

2. Crowd Congestion Index (CCI)

Formulates a normalized compaction metric comparing violated proximity pairs against maximum combinatorial capacity:

CCI = ( Cthresh / max(1, N(N - 1) / 2) ) × 100%

Classified dynamically into Low (<10%), Moderate (10-25%), High (25-50%), and Severe (>50%).

3. 2D Gaussian Density KDE

Applies continuous radial Gaussian kernel accumulation centered over each detected pedestrian to pinpoint spatial bottlenecks:

D(x, y) = ∑ exp( - ( (x - xc,k)2 + (y - yc,k)2 ) / (2σ2) )

Normalized to $[0, 255]$ and alpha-blended with the source frame using the OpenCV JET color gradient.
